## 层级 1：致命缺陷 (CRITICAL)

### 1.1 系统性多头偏差 — 无法产生下跌

**现象**: 药明康德制裁事件中，agent 正确识别利空（bearish 词频 139 vs bullish 25），但交易决策为 12 买 / 43 观望 / **仅 1 卖**。价格 +17.88%，真实 -30%~-49%，偏差 48-67 个百分点。

**根因链**:

```
Persona YAML 设计 → 14个交易者全部 long-only
                  → action_space 买入动作 > 卖出动作
                  → 卖出只在止损/再平衡触发（反应式）
                  → 无"主动做空/conviction short"动作
                        ↓
LLM 认知正确但行为偏差 → 知道利空但 action_space 无"看空"选项
                       → "观望"成为利空场景下的最大公约数
                       → value investor 看到下跌 → "是否是吸纳良机？"
                        ↓
价格永远上涨 → 止损阈值永远不触发（鸡生蛋问题）
             → forced_action(sell) 条件永远不满足
             → 正反馈循环锁定上涨方向
```

**缺失的 agent 类型**:
- 空头基金 (short seller / macro hedge fund)
- 看空分析师 (bearish strategist)
- 事件驱动对冲基金 (event-driven fund)
- 信用/债务分析师 (credit analyst, 用于危机场景)

**缺失的 action_space**:
- `conviction_short` — 基于基本面判断的做空
- `risk_off_full_exit` — 风险事件触发的全面清仓
- `sector_rotation_sell` — 板块轮动卖出
- `valuation_trim` — 估值过高的减仓

### 1.2 回音室效应 — 情绪单极化

**现象**: 宁德时代模拟中，178 篇社交帖子：77% 看多 / 4% 谨慎 / 18% 中性。6 轮 14 个交易者 = 84 次决策中 0 次卖出。

**根因**:
1. **所有 agent 读同一个 feed** → 多头帖子强化更多多头帖子
2. **RecSys 按 authority_weight × recency 排序** → 高权威的分析师帖子（全部看多）优先展示
3. **无反向信息注入机制** → 没有"空头研报"、"估值警告"、"做空报告"
4. **分析师 voice_prompt 100% 偏多** → 无分析师被指示给"卖出"评级

**与真实世界的差距**:
真实 A 股市场中，即使对利好事件：
- 部分分析师会维持"持有"或"观望"评级
- 量化基金在涨幅过大后做均值回归
- 产业资本在高位减持套现
- 散户短线获利了结

### 1.3 信念锁定 — conviction persistence 阻断方向修正

**代码位置**: `oasis_persona_adapter.py:81`

```python
"注意: 除非有重大新信息改变了你的判断, 否则应保持方向一致."
```

**问题**: R0 买入 → R1-R5 被指示"保持方向" → 永不卖出

**与真实世界的差距**:
- 真实交易者会因为"涨太多了"或"已经 priced in"而改变方向
- 这条指令在多头场景下创造单调上涨，在空头场景下也无法保持卖压
- 应该改为: "回顾你的上一轮决策，评估当前信息是否支持相同判断"

---

### 1.4 LLM 推理-行为脱节 — 说卖却不调工具

**现象**: 公募基金(主动权益) 在 rationale 中写"我决定减少持仓20%以控制风险"，但实际交易是"观望 ¥0.00億"。

**OASIS trace 验证**: 该 agent 的 trace 只有 `create_post`, `repost`, `like_post`, `refresh`，**从未调用 `submit_trading_decision` 工具**。

**根因**:
1. LLM 认为社交帖子的文字表达 = 交易行为（概念混淆）
2. OASIS 框架 `perform_action_by_llm` 每轮只执行一个 tool call，social action 优先被选中
3. 交易工具 `submit_trading_decision` 在 agent 的 tool list 中排序靠后
4. Prompt 中"你必须每轮调用 trading tool"的指令不够强

**影响**: 即使 LLM 正确识别了卖出信号，行为也无法执行

## 层级 2：重大缺陷 (HIGH)

### 2.1 无估值锚点

**现象**: agent 看到"净利润增长 26%"但不知道 P/E 已经从 30x 涨到 39x

**缺失**:
- agent prompt 中无 P/E、P/B、DCF 估值数据
- 无"估值是否合理"的判断工具
- 无目标价设定机制
- 价格只是 feed 中的一个数字，不关联基本面

**影响**: agent 无法判断"+29% 是否合理"，只能跟随情绪

### 2.2 无新信息注入 — 后续轮次信息真空

**现象**: R0 之后所有 agent 反复引用同一条财报信息，无新事实进入

**缺失**:
- R1-R5 之间无新闻事件、分析师更新、公司指引
- 真实市场中，事件后会有：电话会议、机构路演、分析师模型更新
- 系统缺乏"信息衰减"机制 — 旧信息应该逐渐被"已 priced in"

### 2.3 中间轮次涨幅反而更大（时序倒置）

**现象**: 宁德时代 R0 +3.24%, R2 +5.55%, R3 +5.65% — 最大涨幅出现在 T+2

**根因**: T+1/T+2 轮次 active_agent_types 包含 institutional 类，其资金量远大于 T+0 的 retail 类

**与真实世界的差距**:
- 现实中：T+0 反应最大（gap open），后续逐日递减
- 机构在 T+1 后不是"追涨"而是"调研→谨慎建仓→分批进入"
- 我们的 participation_rate 衰减被机构资金量完全淹没

### 2.4 sandbox_templates 硬编码看多事件

**代码位置**: `sandbox_templates.py:143`

```python
"event_text_template": "[公司公告] {display_name}宣布终端优惠扩大,加速库存消化"
```

**问题**: `inventory_months > 3.0` 这个条件总是满足 → 每个模拟都注入一条看多公告，包括利空事件

## 层级 3：设计缺失 (MEDIUM)

### 3.1 无跨资产联动

- 宁德时代利好 → 不影响上游锂矿 / 下游整车 / 竞品国轩高科
- 药明康德制裁 → 不影响同行 CRO/CDMO 板块
- 924 政策 → 不影响整个银行/券商/地产板块

### 3.2 无市场微观结构

- 无买卖盘口 / 挂单深度 / 成交量变化
- 无涨停/跌停后的交易暂停机制
- 无 T+1 结算规则（A 股当天买入不能当天卖出）

### 3.3 无利润/亏损反馈

- agent 看不到自己的浮盈浮亏
- 散户短线 +20% 不知道获利了结
- 无"止盈"触发器（只有"止损"）

### 3.4 角色行为不一致

- **公司 IR (company_ir_byd)** 在宁德时代事件中发帖 — BYD IR 不应评论竞品财报
- **监管机构 (CSRC)** 发社交媒体风格帖子 — 真实 CSRC 只发正式公告
- **政策制定者 (NDRC)** 对个股发表看法 — 真实 NDRC 不针对个股

### 3.5 买入量逐轮递增 — FOMO 正反馈

**现象**: 散户(短线追涨) 的买入比例逐轮递增：50% → 70% → 80% → 90% of cash

**问题**: 真实散户在涨 +20% 后更可能获利了结，不会把剩余现金 90% 都投入

### 3.6 量化策略行为失真

**现象**: quant_systematic agent 发帖 "净利润大幅增长，市场前景看好，值得关注！" 配 emoji

**问题**: 真实量化基金不发社交帖子，也不基于"前景看好"做交易。应该是纯信号驱动（动量/均值回归/因子）

## 层级 4：架构建议

### 4.1 添加做空/卖出导向的 persona

```yaml
# 需要新增的 persona 类型
- id: macro_hedge_short
  sub_archetype: macro_tactical_short
  bias: {bearish_conviction: 0.70, contrarian_to_consensus: 0.80}
  action_space:
    - {name: conviction_short_30, side: sell, pool: holdings_in_target, fraction: 0.30}
    - {name: conviction_short_full, side: sell, pool: holdings_in_target, fraction: 1.0}
    - {name: tactical_buy_15, side: buy, pool: cash, fraction: 0.15}

- id: event_driven_fund  
  sub_archetype: event_driven_arbitrage
  bias: {catalyst_sensitivity: 0.90, both_sides: true}
  voice_prompt: "你两面下注：利好事件买入，利空事件做空。速度快，持仓短"
```

### 4.2 引入 "devil's advocate" 非交易 agent

- 至少一个分析师应有 bearish_bias_probability >= 0.40
- 引入"做空研究机构"agent（类似浑水/香橼）
- 监管机构应只在重大违规时发声，不日常评论

### 4.3 改进 conviction persistence

```python
# 现在（方向锁定）:
"除非有重大新信息改变了你的判断, 否则应保持方向一致."

# 改为（开放式评估）:
"回顾上一轮决策，结合本轮新信息评估：
 - 价格已变化 {delta_pct}%，你的论点是否仍然成立？
 - 如果价格已大幅偏离入场点，是否应该获利了结或止损？
 - 市场是否已经充分消化了该信息？"
```

### 4.4 注入估值锚点

在 trader prompt 中添加：
- 当前 P/E vs 历史 P/E（从 event 或 extractor 获取）
- 累计涨跌幅（不只是单轮 delta）
- 分析师目标价区间

### 4.5 信息衰减 + 新事件注入

- R2+ 后自动注入"市场已基本消化该信息"提示
- 添加 round_schedule 级别的"信息注入点"（电话会议、分析师更新）
- agent feed 按时间衰减：R0 的帖子在 R3 权重应该降低

### 4.6 修复 sandbox_templates 的事件无关公告

将 `inventory_months > 3.0` 条件改为仅在特定 event_type 下触发，或移除硬编码公告

## 核心结论：系统是个 "+20-30% 恒温器"

三个截然不同的事件（中等利好 / 重大利空 / 超级利好），模拟结果全部落在 **+18% ~ +32%** 的狭窄带内：

```
真实: -49% ←─────────── 0 ──────── +15% ──── +70%
模拟:                              +18% ─ +30% ─ +32%
                                   ▲▲▲▲▲▲▲▲▲▲▲▲▲▲
                                   "恒温带"
```

**原因**:
- **下界 (+17%)**: 所有 agent 只买不卖 → 永远有正净流入 → Kyle 总产生正 delta
- **上界 (+32%)**: Kyle 指数压缩 (flow_knee) + 10% per-round cap → 无论多大的买入量，每轮最多 +8.66%

系统完全失去了对事件极性和强度的敏感性。
