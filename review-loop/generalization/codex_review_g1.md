# Codex Review — Generalization Test Round 1

## Input
比亚迪Q1超预期 (首次换输入测试，之前28轮都是央行降准)

## Codex 核心诊断

### 1. 参与者权重倒挂
> 比亚迪这种级别的票，碰上 Q1 超预期，真正该出来定价的核心资金是公募赛道基金、头部私募、北上、量化、两融盘、ETF 相关被动资金。结果公募、私募、险资全程观望，主要靠散户把价格打上去。

### 2. 行为脸谱化（三幕戏）
> 先散户抢，后游资接力，再来个做空基金说"情绪见顶，控制风险"出来砸。这种话术太像模型给自己补理由。真到财报超预期，市场分歧不会这么脸谱化。有人追、有人兑现、有人看估值、有人盯全年指引、有人做对冲。

### 3. 价格冲击不自洽
> Round 0，0.61 亿净买盘，ADV 74 亿的大票，直接打出 +2.46%；Round 2，4.45 亿净卖盘，才跌 -0.74%。同一套冲击函数，前后弹性差这么多，不是市场复杂，是模型自己没把价格层说圆。

### 4. P&L 混账
> 个人大股东、产业资本排在收益前列，本质上多数只是持仓市值跟着涨了。把被动持有的账面浮盈拿来当模拟成果展示，混淆了"谁在定价"和"谁恰好持有"。

## Codex 总结
> 这个系统离"可用"还差把真实资金约束、真实参与者权重和真实价格形成机制接上，否则它现在只是会编市场故事，还不会模拟市场。
